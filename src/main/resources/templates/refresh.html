You signed in through PKCE Demo Client, a public client. Spring Authorization Server refuses to issue refresh tokens on the authorization code grant when the client authenticates with ClientAuthenticationMethod.NONE — see OAuth2RefreshTokenGenerator.isPublicClientForAuthorizationCodeGrant. A token that never expires in the hands of a client that cannot keep a secret is exactly what the OAuth 2.0 Security BCP warns about.

The demo therefore registers a second client that keeps a secret and is still required to use PKCE. Sign in through it to exercise the refresh grant.
